# Changelog

All notable changes to `laravel-steadfast-courier-package` will be documented in this file.

## Unreleased

### Added

- Added the documented order, tracking, pickup, return, payment, lookup, and fraud-score endpoints.
- Added extended bulk-order support with guide-compatible request and response handling.
- Added HMAC-SHA256 webhook signature verification and JSON payload parsing.
- Added focused HTTP contract tests for the API and webhook behavior.

### Changed

- Updated the default API base URL and configuration documentation to use `portal.packzy.com`.
- Updated the README with complete API usage, webhook integration, and contributor verification instructions.
